🔐 Authentication

Include your API key in the Authorization header using the Bearer scheme:

Header Format
Authorization: Bearer mistai_YOUR_API_KEY_HERE
Important: Always use HTTPS (never HTTP). Rate limit is 30 requests per minute per API key.

❓ Troubleshooting

DNS Issues?

If api.mistai.org doesn't resolve, use the fallback: https://mist-ai.fly.dev/api/v1/chat

Invalid API Key?

Make sure your key starts with mistai_ and is correctly placed in the Authorization header.

Rate Limited?

You're sending more than 30 requests per minute. Wait a minute and retry.
